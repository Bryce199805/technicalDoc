## 推荐学习路径

1. 建立 Node.js 版本和包管理环境。
2. 理解 JavaScript 模块、事件循环和异步 IO。
3. 掌握 TypeScript、测试、代码质量和构建工具。
4. 再学习服务端开发、性能分析和生产部署。

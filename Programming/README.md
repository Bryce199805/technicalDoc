## 推荐学习路径

1. 先选择一门语言，完成工具链、依赖管理和最小项目环境。
2. 学习语言核心、运行时模型、调试与测试方法。
3. 再补充构建、代码质量、性能分析和部署流程。
4. 跨语言内容通过 Git、Containers、Linux 等目录建立工程联系。

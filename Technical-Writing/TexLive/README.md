## 推荐学习路径

1. 安装 TeX Live 并验证基础编译链。
2. 学习 LaTeX 文档结构、宏包和数学公式。
3. 加入参考文献、图片、表格和自动化构建。
4. 最后建立可复现的论文或技术报告工程。

## 未来扩展

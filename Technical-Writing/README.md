| 主题 | 内容 |

| [Markdown](Markdown/README.md) | Markdown 基础、扩展语法、数学公式与编辑器速查 |
| [TeX Live](TexLive/README.md) | LaTeX/TeX Live 环境与 PDF 排版工具链 |

## 推荐学习路径

1. 先用 Markdown 完成日常笔记、项目说明和知识库内容。
2. 掌握链接、图表、数学公式与 Docs as Code 工作流。
3. 对论文、报告和复杂排版需求，再学习 LaTeX 与 TeX Live。
4. 最后建立术语、模板、引用和自动化发布规范。

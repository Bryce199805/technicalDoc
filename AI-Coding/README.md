## 推荐学习路径

1. 先掌握 Git、终端和项目构建测试流程。
2. 从单一工具的安装、权限与上下文管理开始。
3. 再学习自动化工作流、MCP、Hooks 和多代理协作。
4. 最后建立安全审计、质量评测和团队治理机制。

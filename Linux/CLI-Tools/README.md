# Linux CLI Tools

本目录整理 Shell、现代命令行工具、终端复用器和编辑器配置。

## 当前内容

从 [终端工具安装清单](00-安装清单.md) 开始，再按以下顺序选择：

1. [zsh + Oh My Zsh](01-zsh-ohmyzsh.md)
2. [eza](02-eza.md)、[bat](03-bat.md)、[zoxide](04-zoxide.md)
3. [fzf](05-fzf.md)、[btop](06-btop.md)、[tldr](07-tldr.md)
4. [Zellij](08-zellij.md)
5. [Neovim + LazyVim](09-neovim-lazyvim.md)

目录还包含本地安装脚本和 LazyVim 练习材料。运行脚本前应先阅读内容，并在测试环境验证。

## 未来扩展

- POSIX Shell、管道、重定向、文本处理和退出状态。
- `rg`、`jq`、`yq`、`fd`、`sed`、`awk` 等常用工具。
- dotfiles 管理、跨机器同步和可回滚配置。
- ShellCheck、脚本测试、错误处理和安全执行。
- 终端性能、远程会话和开发环境复现。

# LazyVim Installer

本目录包含 LazyVim 安装脚本和安装后的基础练习材料。

## 当前内容

| 文件 | 内容 |
|------|------|
| [install-lazyvim.sh](install-lazyvim.sh) | LazyVim 安装脚本 |
| [LEARNING.md](LEARNING.md) | 移动、编辑、窗口和快捷键练习 |

运行脚本前应先检查依赖、目标路径和覆盖行为，并备份已有 Neovim 配置。

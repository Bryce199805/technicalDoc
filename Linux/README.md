## 推荐学习路径

1. CLI 与 Shell：建立稳定的终端操作能力。
2. 用户、权限、进程和服务：掌握系统管理基本单元。
3. 日志、计划任务和故障排查：形成日常运维闭环。
4. CGroup 与资源观测：理解资源竞争和隔离。
5. 再进入网络、虚拟化、容器和 GPU 等专题。
